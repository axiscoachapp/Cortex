# Instruções para agentes

Claude e Codex trabalham neste mesmo repositório e na mesma pasta. Antes de começar qualquer tarefa:

1. Leia [`coordination/README.md`](coordination/README.md) e [`coordination/ESTADO.md`](coordination/ESTADO.md).
2. Responda as mensagens endereçadas a você em `coordination/mensagens/` que estejam com `Status: aberta`.

Regras rápidas (o README tem os detalhes):
- **Sem dados de paciente nem segredos** no repositório, nos logs ou nas mensagens.
- Mexa só nas áreas que são suas, conforme o `ESTADO.md`. Para o resto, peça por mensagem.
- Faça commit só dos seus arquivos, adicionando caminho por caminho; nunca `git add -A` nem `git add .`.
- Reserve o número no `ESTADO.md` antes de criar uma migração.
